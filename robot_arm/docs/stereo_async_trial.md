# 비동기 양안 절대좌표 시험 (2026-10-02)

양쪽 CNN 관절/마커 좌표를 UART0로 전달하고, 보정된 두 카메라의 실제 픽셀 쌍으로
삼각측량한 mm 좌표를 오른쪽 보드의 A1 → A2 → 20 ms PWM 경로로 전달한다.
단안 대체, 가상 Z, 가짜 노출 타임스탬프/검증 플래그를 사용하지 않는다.

## 기본값과 명령

Stereo 빌드는 PWM OFF, 비동기 시험 OFF로 부팅한다. LEFT는 좌표 송신 역할이며
PWM/시험 활성화를 거부한다. RIGHT의 기존 오른팔 CH0..CH4만 사용한다. 양팔 제어는 미구현이다.
USB 콘솔 UART1은 921600 8N1, 보드 간 UART0는 115200 8N1이다.

ComPortMaster 등 단일 보드 콘솔에서는 한 글자만 전송한다. 로컬 통합 모니터에서는
대상 접두사와 Enter를 사용하며 운동 명령은 --interactive --allow-motion-commands가 필요하다.
UART 모니터와 테스트는 공유한다. 캘리브레이션 사진·촬영/보정 스크립트와
필터 비교 실험 산출물은 이 공유 패키지에 포함하지 않는다.

| UART 키 | 로컬 모니터 입력 | 의미 |
|---|---|---|
| V | r V | 로봇 PWM 상태 조회 |
| E | r E | LIVE·정지·기준 명령 일치 시 PWM ON |
| T | r T | 비동기 시험 상태 조회 |
| A | r A | RIGHT PWM ON 및 LIVE에서 비동기 양안 시험 ON |
| S | r S | 새 비동기 목표 입력 OFF. 이미 승인된 궤적은 완료 후 유지 |
| X | r X | PWM OFF 및 비동기 시험 OFF. 유지 토크 해제 |

보드 전원을 끈 상태에서 해당 역할의 BOOT.BIN을 SD 루트에 설치한다. 먼저 서보 전원을
분리해 영상/로그/역할을 확인한다. 실제 팔을 지지하고 홈/마지막 명령과 작업 공간을 확인한 뒤
V → E → T → A 순서로 사용한다. E는 홈/마지막 명령으로 팔을 움직일 수 있고,
A는 다음 유효 양안 입력부터 추종을 시작한다. 자동 활성화나 자동 구동 시험은 하지 않는다.
S는 인증된 정지/비상정지 기능이 아니며 X는 토크를 해제해 팔이 처질 수 있다.

## 입력 기준과 한계

운영 소스의 3D One Euro 기본 필터는 원본 3D 승인/재획득 뒤, A1 각도 계산 전에
한 번 적용한다. 기존 2D EMA와 각도 EMA는 유지하고 elbow/wrist/빨강/초록 XYZ를
필터링한다. 독립 2D gripper와 원본 JUMP 참조는 변경하지 않는다.
일반 RIGHT Vitis 빌드에서도 외부 훅 없이 적용된다. 자세한 설정과 별도 미해결
손목 기준 복구 문제는 [One Euro 계약](stereo_one_euro.md)을 따른다.

- 시험 OFF에서는 기존 검증된 노출 시간/공통 epoch/기하/검출 품질 gate를 유지한다.
- 시험 ON의 미동기 쌍은 별도의 async_measured_pose/async_status를 사용한다.
  time_verified=0, control=-2, sync=0 및 원본 메타데이터를 그대로 유지한다.
- 좌우 프레임 ID는 독립적이다. 좌우 sequence 중복/역행을 거부하고 한 프레임을 한 쌍에만 사용한다.
- 시험 ON에서는 수신 나이 250 ms 이내인 최근 RIGHT 프레임에 가장 가까운 수신 시각의
  LEFT 프레임을 매칭한다. 좌우 수신 간격은 100 ms 이하여야 한다. 소비한 프레임보다
  오래된 큐 항목은 폐기하고 각 프레임은 재사용하지 않는다. 큐는 8개로 한정하며
  저장 로그의 FIFO 오프라인 분석과 LIVE 최신성 정책을 구분한다.
- 검증된 노출 메타데이터가 양쪽에 있으면 시험 ON에서도 공통 epoch와 노출 skew ≤1000 µs를
  요구하며 비동기 경로로 우회하지 않는다. 검증된 프레임의 250 ms 보관 만료와
  시험 OFF의 기존 strict 보관/시간/품질 기준은 유지한다.
- 비동기 A1 입력의 dt는 오른쪽 수신기에서 기록한 로컬 CNN 완료 시각의 차이다.
  왼쪽 UART 수신 완료 시각도 같은 수신기의 로컬 시각이다. 이는 노출 시각/노출 간격이나
  양쪽 카메라 동기화 오차가 아니다. 미래 수신 시각과 중복/역행 입력은 계속 거부한다.
- 캘리브레이션의 왜곡 보정·삼각측량·양쪽 재투영 오차·양의 depth·퇴화 검사 유지.
  양쪽 재투영 오차의 기본 한계는 각각 15 px이며 시간 동기화 검증을 대신하지 않는다.
- 모든 stereo 경로에서 카메라별 픽셀 좌표를 push 시점에 τ=0.10 s EMA로 처리한 뒤
  삼각측량한다. 미검증 입력의 필터 dt는 수신기 시각, 검증된 입력은 노출 시각 기준이다.
  invalid/품질 거부점은 EMA 이력을 갱신하지 않는다. 팔꿈치·손목의 30 px 초과 도약,
  session/시험 모드/시각 검증 상태 변경과 250 ms 초과 간격은 2D 재획득 후보로 분리한다.
  고정 최초 후보와 직전 후보 각각에서 30 px 미만인 서로 다른 3개 입력이 모이면
  새 점으로 재획득한다. 빨강·초록은 손목 거리 ≤2×max(전완 픽셀 길이,80 px)를 검사한다.
  정상 범위의 손가락 개폐는 2D major 재획득을 기다리지 않는다.
- 제어 필수점은 elbow/wrist다. 어깨는 진단용 선택점이며 몸통 좌표계/어깨 폭 정규화에 사용하지 않는다.
  필수점 depth 300..3000 mm, forearm 길이 80..600 mm, 이전 승인 측정 대비
  elbow/wrist 이동 ≤150 mm를 일반 입력 기준으로 사용한다. 초과하면 HOLD하며, 고정
  최초 후보와 각 점 거리 ≤50 mm인 신선하고 유효한 서로 다른 3개 쌍으로 재획득한다.
  불량/오래된 후보와 250 ms 초과 간격은 후보를 초기화한다. 실물 안전 인증값이 아니다.
- 손목 각도용 손가락 3D 좌표는 wrist와 250 mm 이내, 두 마커 간 10..250 mm를
  검사하며 실패하면 손목 각도를 유지한다. gripper는 이 3D 검사와 독립적으로
  같은 카메라의 2D wrist/빨강/초록 좌표로 계산한다. 현재 사용하는 영상에서
  세 점이 모두 보이면 그 영상을 계속 사용하고, 누락되면 완전한 반대쪽 영상으로
  전환한다. 두 영상 모두 불완전하면 마지막 gripper 목표를 유지한다.
  좌우 영상의 마커를 서로 섞거나 누락을 CLOSE로 해석하지 않는다.
  손목 각도를 아직 복원하지 못했어도 유효한 2D gripper 목표는 A2/PWM까지 전달한다.
- 수신 오류/기하 불량/오래된 입력/불량 도약 후보는 새 목표만 거부한다. 입력 소실만으로 마지막 승인 궤적을
  즉시 취소하거나 PWM을 자동 해제하지 않는다. S/A로 시험을 재시작하면 측정 이력을 명시적으로 초기화한다.

로그의 async_test=1은 시험 허용 상태이며 accept가 증가하면 A1 입력 어댑터까지 전달됐다.
async_status=0은 기하/시험 기준 통과이지 노출 동기화 검증이 아니다. A1/A2 안전 거부는
별도 TRACE에서 확인한다. reject만 증가하면 관절 대응, 캘리브레이션 고정 상태,
재투영 오차/점 유효성/sequence/거리 기준을 확인한다. `qL`/`qR`은 좌우 FIFO 잔량,
`qdrop`은 용량 초과로 버린 프레임 수다. `time_gate=RECEIPT_LATEST`는 비동기 LIVE,
`STRICT`는 기본 모드다. `fresh`는 쌍의 더 오래된 입력이 250 ms 이내인지의 진단값이다.
`stale/gap/skip`과 `marker_bad/jump_bad/reacquire`로 폐기·품질 상태를 구분한다.
`PG`의 `JUMP_HOLD/REACQ_WAIT/REACQ_ACCEPT`와 `RQ`의 후보 수·필터 세대를 확인한다.
재획득은 입력 승인이다. 필터 이력은 초기화하지만 A2/FK/20 ms 경로 검사는 우회하지 않는다.

수신 나이/간격 제한은 누적 지연을 제한하지만 실제 노출 시각을 알 수는 없다.
빠른 움직임이나 좌우 입력률 차이는 잘못된 깊이를 만들 수 있으며, 최신쌍과 픽셀 EMA,
15 px 재투영 기준, 150 mm 이전 승인 측정 gate가 노출 동기화나 실제 정확도를 보장하지 않는다.
처음에는 정지 또는 느린 동작으로 시험한다. 실제 노출 동기화/FREX 설계·배선·검증과
카메라-로봇 베이스의 6자유도 외부 보정은 별도 작업이다. 저장되는 절대좌표는 고정된
왼쪽 카메라 rig 기준이며, A1 각도 축만 마주 보는 배치에 맞춰 사람 기준
`(-X_camera,+Y_camera,-Z_camera)`로 계산한다. 로봇 베이스 원점/기울기가 실측
정합됐다고 주장하지 않는다. 자세 각도 정의는
[A1 절대좌표 각도](stereo_absolute_angles.md)를 따른다.
이번 코드/문서 갱신은 물리 활성화나 실보드 시험 결과를 의미하지 않는다.

## m 마진 설정

펌웨어의 m은 RGBY 설정 13개를 순서대로 묻는다. 직접 UART 터미널에서는 숫자+Enter,
현재 값 유지는 Enter만 보낸다. 로컬 모니터는 r m 진입 후 r value 30처럼 숫자와 CR을
보내고, r enter로 빈 CR을 보낸다. both m/both value 40/both enter도 사용할 수 있지만
양쪽 보드가 같은 설정 프롬프트에 있는지 먼저 확인한다. 모든 필드를 마쳐야
RGBY settings applied가 출력되며, 완료 후 a/r a로 연속 추론을 수동 재개한다.
실제 팔 제어 중 설정을 바꾸기 전에 S/r S로 새 시험 입력을 차단하고 팔 상태를 확인한다.
