# Coordinate System

## Camera Coordinate

- +X: right
- +Y: down

## Robot 2D Coordinate

- +X: forward / horizontal
- +Z: up

## 2D Control Mode

Dynamic joints:

- Shoulder Pitch
- Elbow Pitch
- Wrist Pitch
- Gripper

Fixed joints:

- Base Yaw: neutral
- Wrist Roll: neutral

## Input Points

Skeleton:

- Shoulder
- Elbow
- Wrist

Color detection:

- Finger1
- Finger2
